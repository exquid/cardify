# cardify

**Texas Hold'em, after dark.** Браузерный No-Limit Texas Hold'em: один игрок против трёх AI-соперников в турнире Sit & Go на четверых. Тёмный полуночный клуб, изумрудное сукно, сдержанные анимации и звуки без внешних ассетов.

> Версия **0.1.0 — Single Player MVP**. Только виртуальные фишки: без денег, депозитов, призов и рекламы ставок.

## Что внутри

- **Турнир 1 vs 3**: по 2 000 фишек, блайнды 10/20 → 15/30 → 25/50 → 50/100 → 75/150 → 100/200 → … каждые 8 раздач; после конца таблицы — рост ×1.5 (всё в `src/game/config.ts`).
- **Честный движок**: колода тасуется Fisher–Yates на `crypto.getRandomValues` (rejection sampling, без modulo bias). Все ставки, банки, победители и выплаты считает движок; UI только отображает его состояние.
- **Боты** Nova (осторожная), Vex (агрессивный) и Orion (сбалансированный) видят только свои карты и публичную информацию.
- **Table Pulse**: пауза перед flop/turn/river, подсветка того, чей ход, мягкая раздача и переворот карт, перемещение кнопки дилера, полёт фишек к победителю, подсветка выигрышной пятёрки. Режимы Normal/Fast, выключатели звука и анимаций; системный `prefers-reduced-motion` учитывается всегда.
- **Mobile first**: портрет iPhone без горизонтальной прокрутки, safe-area insets, зоны нажатия ≥ 44 px. В альбомной ориентации панель действий уезжает вбок. На desktop работают горячие клавиши.
- **Сохранение**: турнир, настройки и статистика лежат в `localStorage` с версией схемы. После перезагрузки вкладки доступна кнопка *Continue*; повреждённое сохранение не роняет игру, а предлагает новую.

### Управление

| Действие | Клавиша |
| --- | --- |
| Fold | `F` |
| Check / Call | `C` |
| Bet / Raise (открыть слайдер; повторно — подтвердить) | `R` |
| All-in (двойное нажатие — защита от случайного олл-ина) | `A` |
| Next hand | `N` |
| Закрыть слайдер | `Esc` |

В слайдере ставки есть пресеты Min, ½ Pot, ¾ Pot, Pot и Max, кнопки ± на один BB и показ итоговой суммы и доплаты из стека. Недоступные пресеты отключаются.

## Правила и принятые решения

Стандартный No-Limit Hold'em; ниже — то, что важно зафиксировать явно.

| Тема | Решение |
| --- | --- |
| Кнопка дилера | **Moving button**: кнопка переходит к следующему месту, где ещё есть игрок. SB и BB — следующие живые места. Правила dead button не применяются. |
| Heads-up | Дилер = SB, действует первым префлоп и последним постфлоп. Переключение при выбывании автоматическое. |
| Очерёдность | Префлоп первым ходит игрок слева от BB, постфлоп — первый активный слева от кнопки. |
| Мин. ставка / рейз | Bet ≥ 1 BB. Raise ≥ последнего *полного* повышения на улице. |
| Короткий all-in | Не переоткрывает торговлю тем, кто уже действовал. Право рейза возвращается, только если суммарное повышение с момента их хода ≥ полного рейза. |
| BB all-in меньше блайнда | Остальные всё равно уравнивают полный BB. Неуравненный излишек возвращается. |
| Неуравненная ставка | В конце каждой улицы часть ставки, которую никто не покрыл, возвращается владельцу (событие `refund`). |
| Side pots | Слоями по вкладам. Фишки сбросивших идут в банки, но выиграть их сбросившие не могут. |
| Делёж банка | Поровну между лучшими руками. **Нечётные фишки** раздаются по одной победителям по часовой стрелке, начиная с первого места слева от кнопки. |
| Шоудаун | Все оставшиеся в раздаче открывают карты (без мака — упрощение v1). |
| Победа без шоудауна | Если остался один игрок, банк уходит ему, карты соперников не раскрываются. |
| Выбывание | Если в одной раздаче вылетают несколько игроков, выше место у того, у кого на начало раздачи было больше фишек. |
| Конец турнира | Остался один игрок с фишками. Если вылетел человек, сразу показывается экран Defeat с итоговым местом. |

Evaluator распознаёт все 9 категорий (роял-флеш — старший стрит-флеш), кикеры и колесо A-2-3-4-5. Он проверяется на 3 000 случайных 7-карточных руках против эталонного перебора всех 21 комбинации.

### Контракт движка

Все команды — чистые функции `GameState → GameState`: вход не мутируется, состояние сериализуется в JSON.

- `startTournament`, `startNextHand`
- `getLegalActions`, `applyPlayerAction(state, playerId, action, expectedSeq?)`
- `advanceStreet`, `resolveShowdown`, `advance`
- `getPlayerView`, `getPublicView`
- `processBotTurn` (в `bots/`)

Раздача — конечный автомат: поле `hand.pending` равно `action | deal | showdown | complete`. Раздачу улиц и шоудаун UI запрашивает отдельными командами, поэтому паузы Table Pulse никогда не запускают логику повторно. Каждая команда увеличивает `state.seq`. Устаревшая команда (двойной тап, просроченный таймер) отклоняется, поэтому один клик не может сделать два хода или выплатить банк дважды.

### Граница доверия

В v1 движок работает в браузере и от читов не защищён: колода лежит в `localStorage`. Для одиночной игры это приемлемо. В мультиплеере тасовка, закрытые карты и валидация ходов **обязаны** жить на сервере. Движок и views для этого уже разделены: сервер будет отдавать клиенту `getPlayerView`, а не `GameState`.

### Боты (v1)

- **Префлоп**: формула Чена с поправками на позицию, размер стола, число рейзов и pot odds; при стеке ≤ 10 BB — режим push/fold.
- **Постфлоп**: Monte Carlo equity (~300 сэмплов) против случайных рук оставшихся соперников. Equity дисконтируется под давлением ставки и сравнивается с pot odds; учитываются value-беты, полублефы и редкие блефы.
- Характер задают пороги, агрессия, частота блефа и сайзинг. Небольшой шум делает игру живой, но не случайной.
- Решение всегда отображается на `LegalActions` и проходит ту же валидацию, что и ход человека.

## Тесты

`npm test` запускает Vitest: 75 тестов в 6 файлах.

- **Колода**: 52 уникальные карты, равномерность тасовки, crypto RNG.
- **Evaluator**: все категории, кикеры, колесо, board plays, split, роял-флеш, сверка с brute-force.
- **Позиции и очерёдность** при 4, 3 и 2 игроках; ротация кнопки с пропуском выбывших; переход в heads-up.
- **Валидация**: check против ставки, мин. рейз, лимит стека, частичный колл, устаревшие команды, неизменяемость входа.
- **Короткий all-in**: без переоткрытия и с переоткрытием суммой коротких олл-инов.
- **Банки**: несколько side pots, разные победители разных банков, split в side pot, возврат неуравненной ставки, победа без шоудауна, автоматический run-out.
- **Инварианты**: 40 случайных турниров с проверкой сохранения фишек после каждой команды; места 1–4 и единственный победитель.
- **Боты**: в наблюдении нет колоды и чужих карт; только легальные ходы; полные турниры без зависаний; колл олл-ина премиум-руками; различие характеров.
- **Сохранения**: round-trip, повреждённый JSON, неверная версия, подделанные фишки, дубли карт.

## Деплой

`npm run build` создаёт статический `dist/`. В `vite.config.ts` стоит `base: './'`, поэтому сборка работает из любой подпапки.

**GitHub Pages**
1. В репозитории: *Settings → Pages → Build and deployment → Source: GitHub Actions*.
2. Push в `main` (или ручной запуск) выполнит `.github/workflows/deploy-pages.yml`.
3. Игра откроется по адресу `https://<user>.github.io/cardify/`.

**Netlify**: импортируй репозиторий — `netlify.toml` уже задаёт `npm run build` и `dist`.

**Cloudflare Pages**: build command `npm run build`, output directory `dist`, переменная `NODE_VERSION=22`.

Отдельно работает `.github/workflows/ci.yml`: typecheck, lint, тесты и сборка на каждый push и PR.

## Известные ограничения v0.1

- Всё состояние хранится на клиенте, поэтому v1 не защищён от читов (см. «Граница доверия»).
- Упрощения правил: moving button вместо dead button, обязательное вскрытие на шоудауне, без анте и straddle.
- Боты не запоминают стиль соперника между раздачами и не строят диапазоны.
- Звуки синтезируются Web Audio и звучат только после первого касания (требование iOS).
- Реальные проверки проводились в Chromium (Playwright) с эмуляцией iPhone 13, iPhone SE, альбомной ориентации и desktop. На физическом iPhone Safari стоит проверить вручную.

## Roadmap

- **v0.1.x**: уровни ботов Easy/Normal/Hard, статистика сессий, опциональный мак проигравших карт, PWA-оффлайн.
- **v0.2 — мультиплеер**: приватные столы на 2–6 игроков по коду приглашения. Авторитетный Node.js-сервер (тот же `src/game/` без изменений), WebSocket-синхронизация через `getPlayerView`, таймеры хода, reconnect, rate limiting; секретные карты и тасовка — только на сервере.
- **Позже**: spectator mode, история раздач с реплеем.

Никакого P2P-покера с тасовкой на клиентах.
